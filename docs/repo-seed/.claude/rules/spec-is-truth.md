# spec/ 이 정본이다

- 라우팅·이벤트·답변 스키마·이미지 매핑은 `spec/` 네 파일에만 정의한다. 프론트와 서버가 같은 파일을 쓴다(서버가 Python 이면 `spec/router.fixtures.json` 을 같은 테스트가 읽는다).
- `spec/` 을 바꾸면 같은 PR 에서 `docs/spec/` 도 같이 바꾼다. CI 가 diff 를 검사한다.
- 화면 문구·문턱값을 코드 안에 상수로 새로 만들지 않는다. `spec/` 또는 `docs/prompts/` 에서 가져온다.
- 픽스처는 기대값을 먼저 적고 코드를 맞춘다. 실행 출력을 기대값으로 베끼지 않는다.
