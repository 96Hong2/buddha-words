# 광고와 사용량

- 광고 자리는 `AdPlacement = 'extension' | 'continue'` 둘뿐이다. 새 자리를 만들려면 `docs/plan/00-통합-개발-계획.md` 1.6절을 먼저 고친다.
- 금지 자리: 고민 작성 중 · 첫 제출 직후 · 답변 블록 사이 · 경전과 분석 사이 · 대기 화면 · 위기 화면 · **위로 답변 화면** · **진입 카드** · INVALID 화면.
- `loadFullScreenAd` → `loaded` → `showFullScreenAd`. 사전 로드. 한 화면에서 광고 그룹 하나만, 순차 로드.
- 보상은 `userEarnedReward` 에서만 지급한다. `dismissed` 는 취소다. 서버는 보상 토큰을 검증한 뒤에만 Extension 을 생성하거나 이어가기를 허용한다.
- 광고 버튼 안에는 **「광고」 배지**가 붙는다(토스 SSP 「Ad 표기 유지」). 배지를 지우거나 숨기지 않는다.
- **한 화면에 「광고」라는 글자는 그 배지 하나로 끝낸다.** 시트 제목·부제·주석·버튼 라벨에서는 그 말을 쓰지 않고 사용자가 얻는 것을 앞에 둔다(「이야기를 이어가 볼까요?」 · 「짧은 영상이 끝나면 바로 이어서 들어 드릴게요」). 「광고 클릭하면」 류 문구 금지. 광고 컨테이너 안에 우리 글자 없음.
- **베푼 것을 세는 문장을 쓰지 않는다.** 「첫 이야기는 광고 없이 드렸어요」처럼 앞서 무료로 준 것을 상기시키면 다음 요구가 청구서로 읽힌다.
- 광고를 못 띄우는 상황(`isSupported()` false · no fill · 이 기기 광고 끄기)에서는 Extension CTA 를 숨기고 이어가기는 시트 없이 허용한다. 광고 때문에 기능을 막지 않는다.
- 사용량: 하루 첫 NORMAL·DEEP 무료 → 이어가기 4회(광고) → 천장 5회. LIGHT 하루 10회 소프트 상한. INVALID·CRISIS·SOLACE 는 세지 않는다. 기준 시각은 사용자 시간대 자정. 성공한 생성만 센다. 확인이 아니라 예약(`pending` 행 + 멱등키).
- 개발·QA 광고 ID 는 `ait-ad-test-rewarded-id`. 실광고 ID 로 테스트하지 않는다.
