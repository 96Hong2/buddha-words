# 클로드 디자인 업로드 지시 (앱 세션용)

리모트컨트롤 세션에서는 `/design-login` 팝업을 받을 수 없어, 데스크톱 앱에서 따로 올린다.

## 올릴 것

`design-inline/` 이 업로드용이다. `design/` 의 HTML 이 참조하는 이미지를 전부 base64 로 박아 둔 사본이라
경로 문제 없이 어디서든 열린다. (`design/` 은 편집용 원본. 고치면 `python3 tools/inline_assets.py` 로 다시 만든다.)

```
design-inline/
├── index.html                       시안 갤러리 (Overview)
├── foundations/colors.html          색·타이포·에셋 토큰 견본 (Foundations)
├── foundations/_tokens.css          CSS 변수 원본 (참고용, 카드 없음)
├── components/kit.html              컴포넌트 키트 (Components)
├── components/illustrations.html    부처 일러스트 8종·브랜드·모션 (Components)
├── screens/s0-splash-onboarding.html  스플래시·첫 진입 안내 (Screens)
├── screens/s1-home.html               홈·고민 입력, 인디케이터 4상태 (Screens)
├── screens/s2-loading.html            생성 대기, 2단 요청 4구간 (Screens)
├── screens/s3-answer.html             답변 7블록, 실분량 (Screens)
├── screens/s4-safety-errors.html      위기 안내·실패·오프라인·거절 (Screens)
├── screens/s5-archive-settings.html   보관함·소진 시트·설정·앱 정보 (Screens)
└── screens/s6-share.html              공유 카드 3종·공유 시트·랜딩 (Screens)
```

`foundations/_fonts.html` 은 폰트 로드 스니펫이라 올리지 않는다.
`docs/PRD v0.2 (통합·라이브목업).html` 은 PRD 문서라 디자인 시스템 프로젝트에는 올리지 않는다.

## 앱에서 할 일

1. Claude Code 앱을 열고 작업 폴더를 아래로 연다.

```
~/orca/workspaces/chore/부처의-말
```

2. 터미널에 `/design-login` 을 실행해 claude.ai 계정으로 디자인 시스템 권한을 준다.

3. 아래 프롬프트를 그대로 붙여넣는다.

---

## 붙여넣을 프롬프트

```
이 폴더의 design-inline/ 아래 디자인 시안을 클로드 디자인(claude.ai/design) 프로젝트로 올려줘.

- DesignSync 로 프로젝트를 새로 만든다. 이름은 "부처의 말".
- 올릴 파일 (design-inline/ 기준 상대 경로를 그대로 유지한다):
  index.html
  foundations/colors.html
  foundations/_tokens.css
  components/kit.html
  components/illustrations.html
  screens/s0-splash-onboarding.html
  screens/s1-home.html
  screens/s2-loading.html
  screens/s3-answer.html
  screens/s4-safety-errors.html
  screens/s5-archive-settings.html
  screens/s6-share.html
- 각 HTML 첫 줄에 이미 @dsCard 마커(group 값)가 들어 있다. 갤러리 카드는 그걸로 잡히니
  register_assets 를 따로 부르지 않는다.
- 이미지는 이미 HTML 안에 base64 로 들어 있어 따로 올릴 파일이 없다.
- 순서: list_projects 로 확인 → create_project → finalize_plan(localDir 을 이 폴더의 design-inline 으로)
  → write_files 로 localPath 를 써서 올린다. 파일 내용을 대화에 붙여넣지 말고 localPath 로 읽게 한다.
- 다 올린 뒤 프로젝트 URL 을 알려줘.
```

## 참고

- 시안 원본은 `design/`, 업로드용 사본은 `design-inline/`. 수정은 `design/` 에서 하고 스크립트로 다시 만든다.
- 디자인 판단의 근거는 `docs/plan/05-비주얼-디자인-언어.md` 와 `docs/plan/00-통합-개발-계획.md` 1.1절(에셋 반영).
- 토큰 값과 대비비 계산은 `design/foundations/_tokens.css` 주석과 `colors.html` 에 있다.
