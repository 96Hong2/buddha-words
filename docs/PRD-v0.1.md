# 부처의 말 — MVP PRD v0.1

## 1. 제품 한 줄 정의

**고민을 털어놓으면, 검증된 부처의 가르침을 근거로 내 상황을 깊게 풀어주고 오늘 무엇을 해야 할지 알려주는 AI 마음 수행 서비스.**

단순 명언 앱이 아니다.
사용자가 충분히 고민을 적을수록 더 좋은 AI 모델을 사용해 깊이 있는 답변을 제공한다.

핵심 경험: 고민 작성 → 마음 태그 → 핵심 가르침 → 근거 경전 → 쉬운 설명 → 개인화된 풀이 → Action → 공유/보관

## 2. 핵심 사용자 가치

사용자는 보통 이런 상태에서 앱을 연다: 연애로 마음이 복잡함 / 회사 사람 때문에 화남 / 미래가 불안함 / 남과 비교하게 됨 / 돈 걱정 / 아무것도 하기 싫음 / 선택을 못 하겠음.

사용자가 원하는 것은 "집착을 버리세요"가 아니라
**"내 이야기를 읽고 이해한 다음, 왜 내가 이런 마음인지 설명해주고 그래서 지금 어떻게 하면 좋을지 알려주는 것"**이다.

## 3. 메인 사용자 Flow — 홈

첫 화면에서 최대한 바로 고민을 쓰게 한다.

메인 문구: **무슨 일이 있었나요? 편하게 이야기해주세요.**
보조 문구: **자세히 이야기할수록 더 깊은 답을 드릴 수 있어요.**
입력창 아래: ✨ **세 줄 이상 작성하면 더 깊고 자세한 풀이를 받을 수 있어요.**

입력이 늘어날수록 indicator:
- 짧은 고민 `● ○ ○`
- 조금만 더 이야기해주세요 `● ● ○`
- ✨ 깊은 풀이 준비 완료 `● ● ●`

억지로 늘리는 느낌이 아니라 **"내 이야기를 더 알려주면 결과가 좋아진다"**는 보상 구조여야 한다.

## 4. 3줄 기준 정의

화면에서는 "세 줄"이라고 표현하지만 서버는 화면 줄 수를 쓰지 않는다.

Deep Answer 조건: 120자 이상 **또는** 의미 있는 문장 3개 이상. 추가로 고민 복잡도가 높으면 자동 승격.
예: "남편이 바람난 것 같아요. 어떻게 해야 해요?" — 짧지만 중요하므로 고급 모델 사용 가능.

최종 모델 Router = 길이 + 문장 수 + 고민 복잡도 + 안전도.

## 5. AI 모델 라우팅

### A. Basic Answer
대상: 3줄 미만 / 120자 미만의 단순 고민. 저가 LLM. 목표: 빠른 응답·낮은 비용·충분히 유용. 답변 길이 약 1,000~1,300자.

### B. Deep Answer ✨
대상: 3줄 이상 / 120자 이상. 고급 LLM. 화면에서도 명확히 보상한다.
> ✨ 이야기를 자세히 들려주셔서 **깊은 풀이**로 답변했어요.
답변 길이 약 1,600~2,500자. 더 깊게 분석하는 것: 현재 상황 / 갈등 구조 / 감정 / 통제 가능·불가능 / 반복되는 사고 패턴 / 경전과 상황의 연결 / 현실적으로 가능한 행동.

## 6. 가장 중요한 원칙: 경전을 AI가 만들지 않는다

사용자 고민 → AI가 핵심 주제 추출 → 검증된 불교 경전 DB/RAG 검색 → 관련 경전 선정 → LLM이 현대적으로 해석.
경전 원문과 출처는 반드시 **검증된 DB에서만** 가져온다. LLM에게 "관련된 부처님 말씀 하나 만들어줘"라고 요청하면 안 된다.

## 7. 답변 구조

모든 답변은 동일한 구조를 사용해 사용자가 익숙해지도록 한다.

### ① 지금 마음
태그 형태. 예: `#불안` `#비교` `#집착` `#인정욕구`. Deep은 최대 4개.
아래 한 문장: "지금 마음의 중심에는 **남들보다 뒤처질지 모른다는 불안**이 있어 보여요." 진단처럼 단정하지 않는다.

### ② 오늘의 한마디 🪷
가장 기억하기 쉬운 핵심 메시지. 예: "**다른 사람의 속도가 당신의 방향을 결정하지는 않습니다.**"
부처의 직접 발언이 아니라 AI가 풀어쓴 내용이라면 **「오늘의 한마디 · 현대적 해석」**이라고 명확히 표시한다.

## 8. 실제 경전

🪷 이 고민과 닿아 있는 부처의 가르침 — 실제 번역문 + **법구경 ○○장 ○○절** 출처. 아래 `원문 보기`로 경전 원문 / 한역 / 번역문을 확장.

## 9. 경전을 쉽게 설명

📖 쉽게 풀어보면 — 경전만 보여주면 "좋은 말 같긴 한데 뭔 소리지?"가 된다. 반드시 현대적 설명을 붙인다.
예: "이 말씀은 욕망 자체를 무조건 없애라는 의미라기보다, 어떤 일이 반드시 내가 원하는 방식으로 이루어져야 한다고 붙잡을수록 마음이 더 흔들릴 수 있다는 뜻으로 볼 수 있어요."
불교 용어가 등장하면 바로 설명. 예: **갈애** — 원하는 것을 강하게 붙잡거나, 원하지 않는 것을 어떻게든 피하려는 마음.

## 10. 당신의 상황을 깊게 보면

💭 지금 당신의 이야기를 보면 — **이 영역이 제품의 핵심이다.** Basic 약 400~600자, Deep 약 800~1,300자.
경전 + 심리적 해석 + 현실 상황을 연결한다. 다만 정신질환을 진단하거나 치료를 주장하지 않는다.

## 11. 그래서 지금 어떻게 할까요?

🌱 오늘 해볼 일 — 거창한 수행이 아니라 **오늘 바로 할 수 있는 행동 1~3개**.
예: 1) 비교가 시작되는 순간 한 번 멈추기 2) 내가 통제할 수 있는 것 하나 적기 3) 오늘 하루 SNS 비교 금지.
내일 다시 들어왔을 때 수행 여부를 물어볼 수 있다. Deep 최대 3개, Basic 1~2개.

## 12. 마지막 한 문장

🪷 "오늘은 남의 속도가 아니라 내 방향만 바라보세요." 이 문장이 **공유 카드의 핵심 문장**이 된다.

## 13. 생성 대기 화면 — 광고를 넣지 않는다

3~10줄씩 고민을 쓴 직후는 가장 중요한 순간이다. 전면 광고가 나오면 "내 고민 → 광고 수익화"로 느껴진다.
대신 생성 과정을 UX로 만든다. 화면 중앙에 차분한 부처 이미지 또는 연꽃 애니메이션. 순차 텍스트:
당신의 이야기를 살펴보고 있어요 → 닿아 있는 가르침을 찾고 있어요 → 지금 상황에 맞게 풀어보고 있어요 → 오늘 해볼 일을 정리하고 있어요. 1~2초마다 자연스럽게 변화.

## 14. 부처 이미지 방향

부처를 감정 캐릭터처럼 과도하게 변형하지 않는다. ❌ 화난 부처 / 우는 부처 / 놀란 부처 / 밈.
대신 **부처의 자세와 주변 환경**이 사용자 마음에 따라 달라진다.
비주얼 스타일: 따뜻한 2.5D / Soft 3D 일러스트. 색: 아이보리, 연한 베이지, 연꽃 핑크, 세이지 그린, 따뜻한 금색.
종교용 앱 특유의 무겁고 오래된 느낌보다 **현대적인 명상 앱 + 불교미술** 중간을 목표로 한다.

## 15. 고민별 부처 이미지

- 😰 불안: 눈을 감고 가부좌한 부처, 잔잔한 물결, 새벽빛. 의미 = 흔들리는 환경 속 평정
- 😡 분노: 표정은 평온, 손은 무릎 위, 붉은 낙엽·바람이 잦아드는 장면. 의미 = 억누르지 않고 지나가게 둠
- 💔 이별·상실: 석양, 떨어지는 연꽃잎, 넓은 여백. 의미 = 무상과 놓아줌
- 🥲 비교·자존감: 크기가 다른 산들, 각 산 위로 같은 햇빛. 의미 = 다른 길, 같은 가치
- 😵‍💫 고민·선택: 갈림길·여러 돌길. 부처는 길을 가리키지 않고 조용히 앉아 있다. **"AI가 정답을 결정한다"는 이미지가 아니어야 한다.**
- 🌙 잠·걱정: 달빛, 작은 연꽃등, 어두운 남색 대신 따뜻한 밤색

## 16. 이미지 생성 전략

매 답변마다 AI 생성하지 않는다(비용·일관성). MVP는 **감정 10종 × 배경 2종 = 20개** 고품질 이미지를 미리 제작.
LLM이 태그를 반환하면 해당 이미지 선택. 예: `emotion=anxiety` → `buddha_anxiety_02.webp`.

## 17. 광고 전략 — 넣으면 안 되는 곳

고민 작성 중 / 답변 생성 중 / 답변 첫 화면 / 경전과 개인 풀이 사이. 몰입을 깨뜨린다.

### 광고 위치 1 — 답변을 모두 읽은 이후 ⭐️
답변 마지막 "오늘 마음에 도움이 되었나요?" `❤️ 도움이 됐어요`. 그 아래 다음 기능으로 넘어갈 때 전면 광고.
[다른 고민 이야기하기] 클릭 → 전면광고 → 새 고민 화면. 즉 **세션이 끝나는 경계**에 광고한다.

## 18. 광고 위치 2 — 추가 풀이

무료 답변은 완전한 답변을 제공한다. 잘라놓고 광고를 보게 하면 신뢰가 떨어진다.
대신 추가 콘텐츠를 보상형 광고로: [광고 보고 다른 가르침 보기] / [광고 보고 두 번째 관점 보기] → 광고 시청 완료 → 추가 LLM 요청.
이 방식이면 광고 수익 + LLM 추가 호출 비용을 서로 상쇄할 수도 있다.

## 19. 광고 위치 3 — 일일 무료 사용량

하루 무료 고민 3회. 이후 "오늘 무료 상담을 모두 사용했어요." → [광고 보고 1회 더 이야기하기] 또는 [Premium 이용하기].

## 20. 유료 기능

무료 사용자의 핵심 AI 경험 자체는 충분히 좋아야 한다. **개인화 데이터가 쌓이는 기능**을 Premium 가치로 만든다.

무료: 고민 작성 / Basic·Deep 답변 / 경전 보기 / Action / 공유 / 당일 답변 확인 / 하루 기본 사용 횟수
Premium: 📚 지난 고민(날짜별 조회) · ⭐ 마음에 간직하기(즐겨찾기) · 🔍 나의 마음 기록(#불안 32% #비교 24% #관계 18%) · 📊 주간 마음 리포트

## 21. Paywall 추천 방식

⭐를 처음 누르면: "**이 말씀을 간직하고 싶나요?** 지난 고민과 마음에 남은 말씀을 언제든 다시 볼 수 있어요." → [3일 무료로 사용해보기]
또는 초기 MVP는 **첫 저장 3회 체험 → 이후 Premium**. 사용자가 저장 기능의 가치를 먼저 경험하는 것이 중요하다.

## 22. 공유 기능

답변 전체는 너무 길다. **공유 전용 카드**를 자동 생성한다.
카드 구성: 부처의 말 🪷 / `#불안` `#비교` / 오늘의 한마디(큰 글씨) / 작은 글씨로 오늘의 수행 / 하단 "부처의 말 — 내 고민에 맞는 가르침 받아보기".
개인적인 원래 고민 내용은 기본적으로 공유하지 않는다.

## 23. 공유 옵션

"무엇을 공유할까요?" — 오늘의 한마디만(가장 추천) / 경전과 함께 / 오늘의 수행과 함께.
사용자의 실제 고민 내용은 **명시적으로 선택하지 않는 이상 절대 포함하지 않는다.**

## 24. 공유 Growth Loop

친구가 공유 이미지·링크 클릭 → 공유된 말씀 → 짧은 해석 → CTA "요즘 마음에 걸리는 일이 있나요?" [나도 이야기해보기] → 바로 고민 입력창. 회원가입부터 요구하지 않는다.

## 25. 메인 화면 IA

MVP 하단 메뉴 3개: 🏠 이야기하기(홈+고민 입력) / 📖 오늘의 말씀(매일 하나씩 무료, 고민 없는 날에도 방문 이유) / 🔒 보관함(클릭하면 Premium 소개: 지난 고민·즐겨찾기·마음 기록).

## 26. 답변 화면 최종 구조

① 마음 태그 → ② 오늘 당신에게 필요한 한마디 → ③ 부처의 가르침(경전+출처) → ④ 이 말씀은 이런 뜻이에요 → ⑤ 당신의 이야기에 대입해보면(가장 긴 개인화 답변) → ⑥ 그래서 오늘은 이렇게 해보세요(Action 1~3) → ⑦ 마지막 한마디 → `공유하기` `⭐ 간직하기` → 추가 가르침 / 새 고민

## 27. Basic vs Deep 차이

| | Basic | Deep ✨ |
|---|---|---|
| 입력 | 짧은 고민 | 충분한 이야기 |
| 모델 | 저가 모델 | 고성능 모델 |
| 답변 | 1,000~1,300자 | 1,600~2,500자 |
| 마음 태그 | 1~2개 | 최대 4개 |
| 경전 | 1개 | 1~2개 |
| 상황 분석 | 기본 | 심층 |
| Action | 1~2개 | 최대 3개 |
| 관점 | 한 가지 | 여러 관점 |
| 비용 | 낮음 | 높음 |

Deep을 **"프리미엄 답변"처럼 느껴지게 하되 무료로 제공**하는 것이 초기 바이럴에 좋다.
사용자는 "3줄 썼더니 진짜 내 얘기를 읽은 것처럼 답한다"는 경험을 해야 한다.

## 28. LLM 출력 데이터 구조

```json
{
  "mode": "deep",
  "emotionTags": ["불안", "비교", "인정욕구"],
  "coreMessage": "...",
  "scripture": { "source": "...", "chapter": "...", "text": "..." },
  "scriptureExplanation": "...",
  "personalAnalysis": "...",
  "actions": ["...", "...", "..."],
  "closingMessage": "...",
  "visualTheme": "comparison"
}
```
이를 통해 UI 변경 / 공유 카드 / 저장 / 분석 / 이미지 변경 / 모델 교체를 쉽게 한다.

## 29. 개인정보 원칙

첫 화면이나 입력창에 짧게: "이름, 연락처, 회사명 등 개인을 알아볼 수 있는 정보는 가급적 적지 말아주세요."
가능하면 LLM 전달 전 전화번호·이메일·주민번호·계좌번호 자동 마스킹.
Premium 기록 저장 시 **"내 고민이 저장됩니다"**를 명확히 알려야 한다.

특히 중요: **Deep Conversion Rate**(입력 시작 중 3줄 이상 도달 비율) / **Answer Completion Rate**(80% 이상 읽은 비율) / **Share Rate** / **Save Intent Rate**(⭐ 클릭률 = Premium 구매 의향 선행 지표).

## 31. MVP 성공 가설

> **사용자는 좋은 명언보다 '내 상황을 제대로 이해했다고 느끼는 답변' 때문에 다시 온다.**

P0: 고민 입력 / 3줄 유도 / 모델 Router / 검증 경전 RAG / 구조화 답변 / 부처 이미지 매핑 / 공유 카드
P1: 즐겨찾기 Paywall / 지난 고민 Paywall / 광고 / 사용량 제한
P2: 마음 통계 / 주간 리포트 / 수행 기록 / 개인화 추천

## 32. MVP의 가장 중요한 화면

- **화면 A**: "여기에 정말 내 이야기를 적어도 되겠다"라고 느끼게 만드는 고민 입력 화면
- **화면 B**: "어? 이거 생각보다 제대로 답해주는데?"라고 느끼게 만드는 결과 화면

초기 개발 리소스의 대부분을 **입력 UX + 답변 품질 + 경전 신뢰성 + 결과 디자인** 네 곳에 투자한다.
