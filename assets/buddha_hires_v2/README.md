# 부처의 말 이미지 확장팩

## 새 이미지
부드러운 황토색 3D 캐릭터를 기준으로 새로 생성한 PNG 6종입니다. 모두 눈을 뜬 모습입니다.
홈 기본형은 기존 화면 속 비대칭 눈 캐릭터를 참고해 깨끗하게 재제작했습니다.

- `images/01-home-open-eyes.png`: 홈 기본 캐릭터, 비대칭 눈 재제작
- `images/02-listening.png`: 고민 경청과 공감
- `images/03-welcome.png`: 첫 방문 인사와 완료 안내
- `images/04-reading.png`: 경전 설명과 보관함
- `images/05-tea-break.png`: 잠시 쉬어가기
- `images/06-lotus.png`: 오늘의 가르침과 공유 카드

## 해상도와 사용법
- 실제 생성 원본 크기: 1254 × 1254 px. 확대 보간하지 않았습니다.
- 2048px를 요청했지만 생성 도구가 위 크기로 반환했습니다. 2K 또는 4K 원본이 아닙니다.
- 배경은 불투명한 따뜻한 아이보리입니다. 투명 PNG가 아닙니다.
- 앱에서 가로 400 CSS px 이하로 표시하면 약 3배 해상도를 확보합니다.
- 전체 캐릭터가 잘리지 않도록 object-fit: contain을 사용하세요.
- 제목과 문구는 이미지 위에 실제 텍스트로 올리세요. 이미지에는 글자를 넣지 않았습니다.
- 실제 앱 화면에서의 통합 검증은 수행하지 않았습니다.

## 이전 파일 복구 범위
- `legacy-reference/`: 첨부 HTML에서 중복 없이 추출한 기존 이미지 15개. 저해상도 목업 참고용이며 고해상도 원본이 아닙니다.
- `original-documents/`: 이전 대화에 첨부된 HTML 9개와 Markdown 1개를 그대로 보존했습니다. 문서 내용은 수정하지 않았습니다.
- 이전 답변에서 언급된 21종 ZIP 및 별도 고해상도 부처 이미지 원본은 현재 대화 첨부에서 접근할 수 없어 포함하지 못했습니다. 해당 ZIP을 받으면 원본 그대로 추가할 수 있습니다.

## 파일 목록과 재생성
- `manifest.json`: 파일별 크기, 해상도, 배경 투명 여부, SHA-256 체크섬, 출처 구분.
- `prompts.json`: 내장 image_gen 도구에 전달한 실제 생성 프롬프트와 권장 용도.
- 신규 6종은 눈 모양과 시선, 잘림, 얼굴과 재질의 일관성을 육안 확인했습니다.
