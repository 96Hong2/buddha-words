# 행동 로그

- 채널은 토스 `Analytics.log` 하나. 자체 이벤트 테이블·외부 분석 도구를 만들지 않는다.
- 이벤트 이름과 파라미터는 `spec/events.ts` 가 정본이다. 거기 없는 이벤트를 보내는 코드는 CI grep 에 걸린다.
- 페이로드에 싣는 값은 id · 열거값 · 구간(`BUCKETS`)뿐이다. 고민 원문 · 답변 본문 · 경전 본문 · 익명키 · 기기 id · 정확한 글자 수 · 예외 메시지는 싣지 않는다.
- `answer_read_70` 은 답변당 한 번만 찍는다(대표 전환). 스크롤 이벤트에서 중복 발화를 막는다.
- 콘솔 핵심 지표: 활성 `answer_generated` · 대표 전환 `answer_read_70` · 보조 `rewarded_ad_complete` · `save_click`. 이름을 바꾸면 콘솔 설정도 같이 바꾼다.
