# 문구

- 전부 해요체. 다이얼로그 왼쪽 버튼은 「닫기」(「취소」 아님). 명사+명사 종결 금지. 「되어요」는 「돼요」.
- 2중 톤: 「오늘의 부처의 말」만 경구체(「~마라 / ~이다」). 경전은 감수 원문 그대로. 풀이·분석은 친절한 해요체. 행동은 짧게.
- 「오늘의 부처의 말」 아래에 「부처의 가르침을 오늘의 언어로 풀어쓴 말」 소문구 또는 「현대적 풀이」 배지가 항상 붙는다. 부처의 직접 발언처럼 보이게 하지 않는다.
- 쓰지 않는 말: 상담 · 치료 · 치유 · 진단 · 처방 · 증상 · 병명 · 업보 · 죄 · 벌 · 「집착을 버리세요」 · 「내려놓으세요」.
- 광고 버튼은 배지로 광고임을 밝히되, 문구로 되풀이하지 않는다(`ads-and-quota.md`).
- **사용자에게 보이는 글에 「무료」를 쓰지 않는다.** 「지금은 3개까지 보관할 수 있어요」처럼 지금 할 수 있는 것을 적는다. 기획 문서 안에서는 계속 무료라고 불러도 된다.
- Paywall 은 과장하지 않는다(「소중한 마음을 영원히」 금지. 「지난 이야기와 간직한 말씀을 모두 다시 볼 수 있어요」).
- 가벼운 입력을 「올바른 고민을 입력해주세요」로 쳐내지 않는다. LIGHT 답변 + 「세 줄 정도 이야기해보세요」 CTA.
- 위로 답변(solace)에서 「이해해요」로 시작하지 않는다. 겪지 않은 일을 안다고 말하는 문장은 `SOLACE_FORBIDDEN` 에 걸린다. 들은 것을 그대로 비춰 주는 쪽으로 쓴다(「그만큼 오래 버텨 오셨다는 말로 들려요」).
- 위기·위로 화면에서 적은 글이 남아 있다는 사실을 화면에 적는다(「적으신 글은 지워지지 않았어요」). 사용자가 확인하지 않고는 알 수 없다.
- 화면 안 텍스트는 실제 텍스트다. 이미지에 글자를 굽지 않는다.
- 줄표(—, –)를 쓰지 않는다. 가운뎃점(·)과 쉼표로 푼다.
